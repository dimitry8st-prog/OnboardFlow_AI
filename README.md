# OnboardFlow AI

Учебный MVP ИИ-ассистента для адаптации новых сотрудников. Он отвечает по контролируемой CSV-базе знаний, показывает чек-листы и безопасно передаёт чувствительные или неизвестные вопросы человеку.

## Что реализовано

- адаптивный веб-интерфейс в синем и оранжевом фирменном стиле;
- ответы по локальной базе знаний без API-ключа;
- подключение OpenAI Responses API через переменную окружения;
- обязательная эскалация кадровых, юридических и чувствительных запросов;
- чек-листы первого дня, недели и месяца с локальным сохранением прогресса;
- системный промпт со сценариями, шаблонами и примерами;
- 15 примеров диалогов «вопрос → ответ → эскалация»;
- инструкция по настройке под структуру компании;
- пакет для сдачи в Google Docs или Notion: `docs/HANDOVER.md`;
- только вымышленные контакты и сведения.

## Формат сдачи

1. Скопируйте `docs/HANDOVER.md` в Google Docs или Notion.
2. Импортируйте `data/knowledge_base.csv` в Google Таблицу.
3. Для демо без сайта вставьте `docs/system_prompt.md` в ChatGPT или OpenAI Playground.
4. Покажите веб-интерфейс: `http://127.0.0.1:8000`.

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`.

## Подключение OpenAI

Скопируйте `.env.example` в `.env` и добавьте ключ:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5.6-luna
```

Не добавляйте `.env` в Git. Без ключа приложение продолжает работать в демонстрационном режиме.

## Проверка

```bash
pytest -q
python -m tests.run_evaluation
```

Дополнительная проверка:

```bash
curl http://127.0.0.1:8000/api/health
```

## Структура

- `app/main.py` — API, поиск по базе знаний, OpenAI и эскалация;
- `data/knowledge_base.csv` — редактируемая база знаний;
- `data/evaluation_cases.csv` — 20 контрольных запросов;
- `docs/HANDOVER.md` — полный пакет для Google Docs или Notion;
- `docs/system_prompt.md` — системный промпт;
- `docs/dialogue_examples.md` — примеры диалогов;
- `docs/company_setup_guide.md` — настройка под компанию;
- `docs/knowledge_update_guide.md` — обновление базы и новых отделов;
- `static/` — пользовательский интерфейс;
- `tests/` — автоматические проверки.

## Обновление базы знаний

1. Откройте `data/knowledge_base.csv` в Google Таблицах или Excel.
2. Не меняйте названия столбцов.
3. Добавьте запись с уникальным ID и датой актуальности.
4. Экспортируйте таблицу в CSV UTF-8.
5. Перезапустите приложение и выполните `pytest -q`.

## Ограничения MVP

- нет авторизации и разграничения доступа;
- нет реальной HRM/CRM-интеграции;
- прогресс чек-листов хранится только в браузере;
- база обновляется через CSV, без автоматической синхронизации;
- демо-режим использует простой локальный поиск, а не полноценную векторную RAG-систему.
