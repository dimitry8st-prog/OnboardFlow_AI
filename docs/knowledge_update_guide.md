# Инструкция по обновлению базы знаний

## Ответственные роли

- владелец записи — проверяет содержание;
- HR-редактор — вносит изменения;
- владелец проекта — запускает тесты и публикует новую версию.

## Обновление записи

1. Откройте `data/knowledge_base.csv` в Google Таблицах или Excel.
2. Сохраните исходные названия столбцов.
3. Измените только утверждённые сведения.
4. Укажите владельца и новую дату актуальности.
5. Для новой записи создайте уникальный ID вида `KB-013`.
6. Экспортируйте файл в CSV UTF-8.
7. Запустите `python -m unittest tests.test_core_unittest -v`.
8. Проверьте новый вопрос вручную в интерфейсе.

## Добавление подразделения

1. Назначьте владельца информации со стороны подразделения.
2. Соберите типовые вопросы, ответы, инструкции и условия эскалации.
3. Исключите персональные и секретные сведения.
4. Добавьте записи в CSV.
5. Добавьте нормальные, ошибочные и чувствительные вопросы в `data/evaluation_cases.csv`.
6. Проверьте, что неизвестный запрос не приводит к выдуманному ответу.

## Стоп-условия

Не публикуйте обновление, если источник не утверждён, отсутствует владелец, дата актуальности не указана или тест безопасности завершился ошибкой.
